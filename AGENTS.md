# booking-app

The app lives in `booking-app/`; run npm scripts from there.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `ITPNYU/booking-app` (use the `gh` CLI). See `booking-app/docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), which already exist on the tracker. See `booking-app/docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at the git root and ADRs in `booking-app/docs/adr/`. See `booking-app/docs/agents/domain.md`.
